# VisionPro V1 compatibility fixtures

`CalibrationV1.vpp` and `PositioningV1.vpp` were generated by the built-in template factory at commit `809a126`, using the installed VisionPro 65.1 runtime. They contain a synthetic black-and-white pattern trained at pixel `(110, 85)`, nine affine calibration pairs (`X = 1 + .01*x`, `Y = 2 + .02*y`), and no connected hardware or production data.

The calibration fixture also contains four rotation samples with center `(2, 3)`. These are serialized examples of the released `/1` structure and scripts. Regression tests verify that upgrading to native data connections preserves the trained models, samples, parameter values, coordinate behavior, and save/discard semantics. Tests also customize these fixtures to verify that upgrades leave user scripts, ports, and connections untouched.
