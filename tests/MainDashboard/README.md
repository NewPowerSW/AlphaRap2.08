# 主框架与首页回归

先编译实际解决方案，再执行：

```powershell
./tests/MainDashboard/Run.ps1 -AssemblyDirectory '.vp-validation/dashboard-redesign-build/bin'
```

检查 1600×1000、1440×900、1280×800 的中文、英文、西班牙文布局；验证顶部命令、全高导航、KPI 数值与空数据、首页常驻报警表及分类筛选，以及保存/初始化/启动/暂停/停止/清除报警原事件。

整机状态牌覆盖待机、初始化中、初始化完成、运行、暂停及带条数报警的三语显示，检查放大后的文字完整性、底栏布局及点击返回首页的原事件。最小窗口额外输出各状态截图 `machine-state-<状态>-<语言>.png`。测试直接调用显示方法，不改变真实运行状态或触发现场报警。

另外构造 42 个应用页面及可无参创建的流程、配置编辑控件，在实际主框架下检查 579 个文本控件，防止浅色背景继承白色文字、交互控件字体过小及轴点动选项遮挡右箭头。深色导航与品牌区保留浅色文字。外部 VPP 编辑器和现场动态第三方控件不属于离线构造覆盖范围。

测试通过 LicenseContext 设计态构造窗体，显式解绑 MainForm_Load 后显示离线测试窗口。设备清单、生产数量及表格示例仅在测试实例中填充，不操作设备、不保存机器配置。

截图输出到 `.vp-validation/main-dashboard/<运行目录>`，包括三种语言看板、常驻报警表与硬件页，需检查文字裁切、图表刻度和卡片间距。Windows GUI 沙箱限制窗口创建时，应在允许桌面句柄的测试环境执行。
