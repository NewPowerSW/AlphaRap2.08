# 新增标定和 VPP 的内置算法

现有相机页入口保持不变。在相机页点击“添加标定”或“添加 VPP”时，当前配方没有对应文件就建立标准算法草稿。已有文件若完全没有工具、端口、脚本、绑定和业务元数据，也会补齐成标准算法草稿；SDK 自带的空 ScriptData 不算业务内容。自定义 VPP 和主动建立的空草稿保持原样。

已有相机的空标定／VPP 可以直接点击“编辑 TB”补齐，无需删除相机或文件。补齐只更新内存，点击主界面“保存”后才落盘；放弃修改会恢复原空文件。程序启动、配方加载仍只读取算法，不自动替换生产算法。

第一版内置范例的工具数据曾由脚本传递，编辑器没有显示连接。普通定位 `/2` 和标定 `/4` 范例使用 VisionPro 原生数据绑定。打开未修改过脚本、端口结构或连线的旧版范例编辑时会升级草稿，保留训练模板、九点模型、曝光、离线图像和旋转样本。第一、二版标定升级后保持“模板定位（兼容）”，切换到圆心或双线交点由应用人员明确选择。第三版升级保留原有精定位设置，增加旋转的九点依赖与机械中心输出。自定义范例不自动替换。升级同样经过主保存和放弃修改路径。

## 编辑器中的连接

根输入中的相机与离线设置连接到 `AcquireImage` 子块。它输出的原始图像同时连接到 `LocatePattern.InputImage`、`Calibration.InputImage` 和根 `OutputImage`。

`LocatePattern.Results` 与 `Calibration.Calibration` 连接到 `PositionResult` 子块；它计算的 `Accepted/x/y/A/Score/MatchCount/Calibrated` 分别连接到同名根输出。可以展开子块端口查看、修改连接和单步运行。采集子块内部保留标准 `CameraCapture` 工具，用于按 SN 配置实际采集。

`UseCalibration` 控制定位结果是否使用有效九点模型，普通 VPP 默认为 true。标定页面拍照自动保持 false，防止把机械坐标再次当作像素采点。匹配仍使用原始图像，标定后的图像不再串到定位输入。

## 添加标定

相机页的标定卡提供“采点方式”“设置找边”“试拍”和“采集此点”。新标定默认使用圆心。试拍取得照片后可以直接拖动黄色圆形或黄、蓝两条测量线，并检查允许的边缘拟合误差。图像已拍到但找边失败时也可用该照片设置。调整找边或切换采点方式前，先清空现有采样。清空采样保留已计算模型，重新采点、应用后经主保存发布。

在“高级 TB”可以配置 PM 跟随、模板训练、卡尺极性和搜索宽度等参数：

- `AcquireImage`：按相机页绑定的 SN 采图，采用本标定的曝光。
- `FindCircle`：用卡尺边缘拟合圆，采点坐标取拟合圆心。配置预期圆、搜索宽度、边缘极性、卡尺数量和剔除点数。圆心模式的 `A=0`，不测量特征方向。
- `FindLine1`、`FindLine2`、`LineIntersection`：分别拟合两段边缘并计算两条直线的交点。分别配置预期线段、卡尺搜索方向、搜索宽度和极性。这里计算拟合直线的交点，允许边缘所在拟合段的延长线相交，但交点必须落在图像内。
- `LocatePattern`、`CoarsePose`、`FeatureFixture`：可选 PM 粗定位及测量区域跟随。启用后先训练 LocatePattern，再在 FeatureFixture 输出图像中调整圆和线的测量区域；区域使用 `CalibrationFeature` 空间。夹具只采用 PM 的平移和旋转，不采用缩放或斜切。精定位结果经过夹具变换回到原始像素。
- `CalibrationPoint`：选择当前分支并校验拟合质量，将最终像素坐标连接到根 `x/y/A`。找圆或交点失败不会退回 PM 的坐标。
- `Calibration`：N 点坐标标定工具。页面仍通过九组以上像素与机械坐标点执行“应用到本相机”，同时更新内置采点算法及该相机下的目标 VPP。
- `RotationCenter`：固定相机、固定 XY、吸嘴或工件随 R 轴旋转时的中心计算工具。

标定采点算法始终输出原始图像坐标，不会因为已经应用九点标定而将机械坐标再次作为像素采样。

### 九点采样操作

1. 选择相机 SN、配方和曝光，建立标定。也可以先完成相机标定，再添加生产 VPP；新增 VPP 后需重新应用九点。
2. 在标定卡选择“圆心”或“两线交点”，点击“试拍”取得照片，再打开“设置找边”。把图形拖到目标边上，使用此设置后可再试拍验证。特征移动范围超出固定测量区域时，在高级 TB 中启用 PM 跟随并在夹具图像中配置测量区域。
3. 保持 Z 和 R 一致，将点分散到视野范围。到达每个位置后输入实际机械 X/Y，再点击“采集此点”。成功时自动写入本次像素与机械坐标并清空输入框，失败保留输入便于重试。
4. 采满九点后点击“应用九点”，检查本相机及全部目标的标定残差。只需要九点时，点击主界面 Save 即可结束。使用独立位置验证实际精度。
5. 需要旋转中心时，九点应用成功后进入“2 旋转标定（可选）”；可以在同次草稿中继续，无需先保存一次。九点不足、未应用或已失效时该入口不可用。

根输入 `FeatureMode` 为 0 圆心、1 双线交点、2 PM 兼容；页面选择写入相同端口。`UsePatternFixture` 控制粗定位。几何质量默认 `MaxFitRms=0.5` 像素、`MinCirclePoints=12`、`MinLinePoints=6`、`MinLineAngleDegrees=10`，可在 TB 调整。有效边缘点不足、残差超限、近似平行、交点越界或特征缺失会拒绝采点并清除旧输出。根输出 `FitRms` 为圆的 RMS 或两条线中较大的 RMS；兼容 PM 模式为 NaN。几何模式的 `Score` 为用于拟合的边缘点比例。

这些门限只控制当前拟合质量，不代表设备的绝对标定精度；镜头、成像、坐标配对和机构重复性仍需现场验证。各生产 VPP 的定位方式继续保持原有 PM 模板定位，本次精定位方式作用于标定采点和旋转采样所用的像素特征。

### 旋转采样操作

旋转必须依赖当前相机、当前配方中已成功应用的至少九点模型。窗口按以下步骤操作：

1. 固定相机和 XYZ，只旋转吸嘴或工件的 R 轴。选择偏离旋转中心的同一圆心或双线交点，沿用九点时的精定位方式；特征位于旋转中心时无法计算旋转轨迹。
2. 转到一个角度，输入 R 轴**实际角度**，点击“采集此角度”。定位成功就把新照片的坐标与本次角度同时加入表格。
3. 至少采三组不同角度，建议用覆盖较充分范围的多组数据。表格允许修正角度、删除点；像素保持原始精度。重复角度、覆盖不足、点位不动或无效数值会拒绝计算。
4. 点击“计算旋转中心”，查看机械中心（mm）、像素中心和拟合 RMS（px）。保留独立角度检查结果，再点击“完成”保留内存草稿，最后由主界面 Save 写入当前配方；“取消修改”恢复进入窗口前的旋转数据。

相机 SN、配方、九点点对、实际模型或目标 VPP 的应用版本变化后，旋转入口会重新检查九点。修改标定算法或重新应用九点会撤销旧旋转结果并保留旧样本供查看；旧样本必须清空后重新采集，不能混入新模型。已升级旧范例中的旋转数组也保留，但没有当前九点的来源记录，需清空重采。

### 旋转工具接口

窗口写入以下根数组，它们分别原生连接到 `RotationCenter` 子块：

- `RotationPixelX` → `PixelX`：每次拍摄同一特征得到的 x。
- `RotationPixelY` → `PixelY`：对应的 y。
- `RotationAnglesDegrees` → `AnglesDegrees`：对应的 R 轴实际角度，单位为度。

`Calibration.Calibration` 原生连接到子块 `CalibrationModel`。把根输入 `RunRotation` 设为 true，或单独运行 `RotationCenter`，都必须有至少九点的有效模型。计算本身不采图或移动设备；页面采样仍需有效精定位。`CenterX/CenterY/RmsError` 保持原始像素单位，新增 `MachineCenterX/MachineCenterY` 为机械坐标 mm，`RotationValid` 表示本次工具计算有效。页面另外检查样本来源及九点版本，直接编辑数组不等于完成页面的有效发布流程。

算法按实际角度拟合 x/y 的正弦、余弦轨迹，支持仿射成像下的椭圆投影。机械中心先将每个样本经九点转换，再按实际角度拟合。重复角度、角度覆盖不足、非有限值、点位不动及长度不一致都会明确报错并清空旧结果。页面拍照和生产调用自动把 `RunRotation` 恢复为 false，继续采图定位。

本工具提供旋转中心计算，不执行轴运动，也不把像素中心直接当作机械轴坐标或自动加入运动补偿。机械坐标使用九点转换关系处理，具体吸嘴偏置和目标运动由应用流程决定。超出同一平面与仿射成像条件的装置需要另行验证模型。

## 添加 VPP

点击“添加 VPP”后，自带连接好的 `AcquireImage`、`Calibration`、`LocatePattern` 和 `PositionResult`。应用人员只需训练特征，调整匹配分数、搜索区域和角度范围。

在新 VPP 的“编辑 TB”窗口顶部可选择定位模板。默认是“普通定位（单目标）”；选择“多目标匹配计数”并点击“使用此模板”，即可按同一个已训练的模板查找多个重复目标。“多目标匹配计数”预设查找数量为 10，`MatchCount` 返回实际匹配数，`x/y/A` 对应结果列表的第一项。

选好模板后，在同一窗口配置取像、训练、搜索范围和试跑。窗口关闭时选择保留修改，再到主界面保存。补齐旧空文件时也能选用模板。已确认的算法草稿和已有内容的 VPP 打开后直接显示自身的工具链。

应用项目可在启动组装时调用 `VpAlgorithmTemplates.RegisterPositioningTemplate`，提供唯一 ID、三语名称和生成已连线 ToolBlock 的工厂。工厂每次返回独立实例，并保留标准定位端口和 `Calibration` 九点工具，额外的业务端口可自行定义。登记后的模板自动出现在“编辑 TB”的模板列表。

两种模板默认匹配分数均为 0.8，搜索区域为整张图像。普通定位默认查找一个结果。输出包括：

- `Accepted`、`MatchCount`、`Score`：本次匹配判定、数量和分数。
- `x/y/A`：定位位置及角度，A 的单位为度。未标定时 x/y 为原始图像坐标；标定后通过坐标转换输出机械坐标。
- `Calibrated`：是否已经使用有效的坐标标定。
- `OutputImage`：本次输入图像，方便离线检查。

模板始终在原始图像坐标下匹配，然后转换位置与方向，因此应用九点标定后无需重新按机械单位训练模板。失败、未训练或未匹配时不会沿用上一个产品的有效坐标。

相机 SN、曝光和错误语言由所属页面更新。`UseInputImage=true` 时使用 `InputImage` 进行离线调试；自动运行状态拒绝该模式，生产前应取消勾选并保存。创建模板不会连接相机，生成的 VPP 脚本只引用标准 VisionPro 运行库。

流程图调用不需要绑定上述内部采集、语言和离线调试端口。在 TB 中另加的业务输入仍会正常出现在流程节点参数中。

## 保存与配方

新增算法、训练、九点标定和旋转工具输入都留在当前配方的 VPP 草稿中，由主界面“保存”统一提交。编辑窗口确认只保留草稿，配方切换沿用已有的保存／放弃处理。机器级相机配置与标定点仍保存在原有配置位置，不增加配方选择入口。

标定点按完整浮点精度写入配置，表格显示的小数位不影响模型或回读。旧配置若已舍入点对且与 VPP 内模型不同，需要重新应用九点后才能进入旋转步骤。

本站单点生产使用旧配方 `tb_H1_Visdata` 的第一行作为兼容定位判据。配方载入时严格检查该行的上下限顺序，其他历史预留行的原值与启用标志继续保留，不因尚未设置的 `0～0` 范围阻断载入。所有启用行仍须具有有限数值；第一行的无效范围仍会阻止载入并清除旧判据快照。
