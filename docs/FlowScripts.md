# 节点 C# 脚本功能退役说明

**当前版本已移除【C# 脚本】和【代码模块】。** 脚本源码编辑、输入输出端口编辑、对象调用插入、编译检查、脚本缓存和脚本调试入口均不再提供。当前操作以 [流程设计器使用说明](FlowProgrammingUsage.md) 和 [工具箱说明](FlowToolboxUsage.md) 为准。

保留本文件路径是为了让已有说明链接能明确指向当前状态，不作为旧脚本使用教程。

## 已保存的旧节点

旧 Script／Code 定义可读取以便核对与处理，但校验和运行会拒绝这些执行方式，不会运行旧脚本或把它默默改成另一设备动作。

打开节点后，明确选择【现有功能】配置实际对象、方法和参数，或选择【仅判断条件】配置数据条件，再核对 NEXT／CASE、超时、报警及下游数据引用。也可解除引用后删除旧节点。取消编辑保留原定义；主【保存】统一提交确认后的配置。

## 现有功能如何替代

轴、IO、VPP、常量、Device、托盘和 DataForm 仍在原页面建立实际对象；节点选择该对象声明的方法。输入通过固定值或【绑定数据】设置，输出由方法声明，下游可直接选择来源节点字段，无需定义脚本端口。

新的设备协议和业务方法由软件开发人员为实际对象实现并通过 IFlowObject 声明，然后在工具箱和节点编辑器复用。当前不提供代码模块发现、模块资源映射或模块出口编辑。

节点断点、单步、继续及输入输出快照仍然可用；节点前等待与主初始化、启动、停止入口不变。有关保存和恢复见 [操作 SOP](AlphaRap操作SOP.md)。
