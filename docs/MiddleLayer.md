# MiddleLayer 开发说明

对外继续使用 `MiddleLayer.xxx`。功能实现按以下文件维护：

- `MiddleLayer.cs`：共享页面、任务引用和运行标记。
- `MiddleLayer.Startup.cs`：机器配置、页面创建、启动顺序、权限及退出清理。
- `MiddleLayer.RunControl.cs`：初始化、启动、暂停、停止及操作提示。
- `MiddleLayer.Modules.cs`：模块周期和复位回调、异常隔离及停止策略。
- `MiddleLayer.Motion.cs`：伺服、电机保护和输送线暂停快照。
- `MiddleLayer.Recipe.cs`：模块配方读取、托盘刷新和视觉模型切换。
- `MiddleLayer.Alarms.cs`：电机报警复位与 SDK 报警表加载。
- `MiddleLayer.Language.cs`：控件登记、显示刷新、语言切换通知及权限显示。
- `MiddleLayer.LanguageText.cs`：三语文本索引、消息底稿和 XML 缓存。

## 运行约定

固定页面的创建顺序保持模块依赖关系。窗体类型在第一次使用时索引，同一窗体实例只登记、初始化一次。需要重新读取模块数据时调用模块对应的读取入口。

初始化、暂停和停止通过主流程明确调用 SDK。运行中取消重新初始化会直接返回；重新初始化会清除旧运行标记。停止操作只发送一次流程停止指令，手动任务取消后只停止一次全部电机。原有 200/500 毫秒等待继续保留。

周期回调异常触发报警后继续处理其他模块；伺服和复位等操作失败时还会停止生产。模块异常的完整堆栈保留在调试输出，需要停止生产的异常同时写入运行日志。日志失败不会阻止报警和停止。

输送线暂停记录首次状态，重复暂停保留该快照；恢复成功或完全停止后清除快照。电机保护持续读取当前 SDK 控件列表和轴 IO 状态，设备列表可变化，不缓存硬件对象集合。退出时先停止后台扫描，再关闭伺服。

## 语言与性能

文案按语言及“窗体/键”建立内存字典。读取文案不再执行 XPath；保存语言设置、重载语言包后重建索引。现场译文优先、三语底稿、并发补写和编辑数据保护继续遵循 `docs/Localization.md`。

窗体类型扫描只执行一次。重复的初始化、停止及电机停止调用已合并，报警清除中的空循环已移除。周期任务直接遍历 SDK 当前模块列表，避免每个扫描周期复制列表。

补偿表仍由应用流程通过 `GetCompensationTable` 显式读取；MiddleLayer 不自动将补偿值加到视觉结果。

## 验证范围

`tests/VisionRuntime/Run.ps1` 覆盖视觉、三语界面、窗体复用、初始化/停止/暂停、模块异常隔离、完整语言索引和扫描线程退出，共 62 个离线场景。测试中的模块、流程及设备列表使用独立替身，不运行真实设备。

测试日志中的 `PERF` 行对比相同机器上的 10 万次 XPath 和索引查找，仅用于评估文案查找，不代表整机提速倍数。

离线测试不验证实机伺服、输送线、电机停止时序和采集。配方读取继续沿用各模块的 SDK 接口及默认配方回退行为，不提供跨模块的数据回滚事务。
