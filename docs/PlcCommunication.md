# 汇川 PLC 通信会话

汇川 H5U 驱动属于 AlphaRap 应用；通用流程框架只负责将当前停止令牌传到同步对象方法、原生工位事件和手动动作。框架与 NPSDK 的这项兼容扩展随框架包 6.2.0 发布。

## 连接与执行

- `new INOVANCE()` 仍使用连接编号 0；`new INOVANCE(id)` 绑定其他编号。构造和设计器预览不启动进程或连接硬件。同编号实例共用一个会话，连接、读取及写入使用同一个请求队列，不再各持读写锁。
- 显式调用 `Connect(host, port, timeoutMs, token)`，或在初始化流程中选择“连接 PLC”对象方法。保留 `Connet`、`Init_ETH_String` 和 `Exit_ETH` 旧签名。每个会话一个隐藏的本机子进程，原生 ABI 和现有汇川 DLL 不变，读写不经过新的 Modbus 地址映射。
- 旧连接入口总上限 3000 ms，最多三次握手；旧读写入口总上限 1000 ms。新结果接口可指定 1–60000 ms，总时限包括排队、进程启动和应答。连接被拒绝后最多按 100/200 ms 退避；连接超时、取消或任何数据操作均不自动重试。
- 没有新增配置文件、保存按钮或配方入口。“连接 PLC”节点参数随现有流程工程通过 MainForm Save 保存；业务地址、端口和用户输入不翻译。本仓库没有已配置的 PLC 连接调用，迁移时须使用现场实际端点，代码不填入假定 IP。

## 停止、故障与重连

父进程通过继承的匿名管道向子进程发送一条请求，再读取一条完整应答。同一通道不会并发请求。DLL 没有在主进程执行；不依赖没有确认签名的原生超时设置接口，也不使用 `Thread.Abort`。

请求超时、运行令牌取消或显式断开时，父进程终止自己拥有的通信子进程、确认其退出并收回管道。连接及其迟到数据一并废弃，后续操作返回未连接；只能显式重新连接。新连接和断开会使旧队列代次失效，旧排队命令不能落到新端点。仅排队中的请求超时或取消不会中断另一个请求占有的连接。

进程退出与管道收回各允许最多 1000 ms 清理时间，另受 Windows 进程调度影响。不能完成回收时保留旧进程和任务引用，后续连接必须先确认它们结束，不创建并行替代连接。正常退出调用 `CloseAll`；父进程意外退出时，子进程的独立看门线程也会结束阻塞中的进程。

写入已进入管道后中断、通信断开或原生返回失败，都保守标记 `WriteOutcomeUnknown` 并记录报警日志。PLC 可能已经执行写入，程序不会自动重发，也不会自动恢复生产。须由操作人员核对设备实际状态后处理。关闭通信连接不等于撤销已写入的动作，设备停止动作仍由原有整机/PLC 安全逻辑负责。

## 数据与兼容性

`ReadPlcResult`、`WritePlcResult`、`Connect` 返回 `PlcResult<T>`：成功、未连接、参数无效、超时、取消、驱动失败和子进程失败分别表示。成功数据 `0` 和 `-999` 都是有效值，失败没有可供条件判断的数据。流程对象方法使用 `RequireValue`，取消抛出取消异常，其他通信失败进入流程故障。PLC 等待节点的每次读取也受剩余等待时间和流程令牌限制。

旧 `ReadPlc` 仍保留失败字符串 `-999`，以及旧多值拼接格式；旧调用不能只靠这个字符串区分合法的 `-999`，新代码应使用结果接口。旧字符串读写和布尔写入接口仍可用，取消向上抛出，不继续后面的节点。

地址仅接受完整大写 D/R/X/Y/S/M 前缀和非负十进制编号，缺失前缀不再默认写入 Y 区。修正已有心跳读取 `6804` 为 `D6804`。字地址的读取长度以 16 位字为单位，32 位整数/浮点数要求偶数字数；位地址按位数读取。新结果接口的多值字符串以逗号分隔。

写入先完整验证所有数值，再发送一次：16 位有符号数、完整 32 位有符号数、有限单精度浮点数；位值仅允许 0/1。16 位值写一个字，32 位值写两个字，不再无条件写两倍长度。UTF-8 字符串按字数写入，奇数字节补零；读取没有零结束符时保留完整字符串。数值转换沿用现有区域格式，不修改 UI 编辑值。

部署仍须提供原有 x64 `StandardModbusApi.dll`、`ModbusTcpAPI.dll` 及其运行依赖，和同版本 AlphaRap EXE、框架及 NPSDK。子进程通过同一个 EXE 的内部入口启动，入口在单实例锁、窗体创建和设备初始化之前分流，不需要增加用户操作。

## 验证

`tests/PlcCommunication/Run.ps1 -AssemblyDirectory <构建目录>` 编译实际驱动源代码，用独立假驱动进程验证共享串行会话、有效零/负数、编码范围、排队时限、永久阻塞取消、迟到应答隔离、写入未知、断开/重连代次、进程崩溃、父进程退出和三语诊断。另通过真实 AlphaRap EXE 与原有汇川 DLL，只连接 `127.0.0.1` 的无应答测试服务器，检查实际发包、取消关闭连接和超时。

离线检查不替代现场 PLC 地址表、写入结果、设备动作和安全停机验证。扫码器、串口及其他厂商设备尚未切换到这套会话机制。
