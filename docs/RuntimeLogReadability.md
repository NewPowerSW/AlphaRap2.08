# 运行日志显示

运行日志页按时间、类型、工位、节点和事件显示。FlowChart 的 Module、Entry、Run 和节点编号保留在原始日志中，列表提取工位和节点名称，并将运行事件显示为简短提示。

例如，`DownConveryor` 的 `下流道阻挡上升1.3` 出现 `Timeout after 5000 ms` 时，事件列显示“等待超时（5 秒）”。即使异常内包含 `OperationCanceledException`，仍显示外层的实际超时原因。原记录的 RUN/ERROR 类别不会被显示摘要改写。

下方默认打开“详情”，提供时间、类型、工位、节点和事件，自动换行。切换“原始日志”可查看并复制完整内容，包括运行编号、节点编号、出口目标和异常堆栈。拖动分隔条可调整列表与详情高度。刷新保留选中记录和详情页签。

旧控制日志也可以显示，例如 `Gantry+++++++++++++++Pause` 显示为工位 `Gantry`、事件“收到暂停指令”；运行内核的 `Paused` 显示“已暂停”。同一模块已处于暂停请求状态时，再次收到暂停指令仍执行暂停回调，但不重复写入同一控制指令日志。恢复运行后的新暂停会重新记录。历史重复记录、节点事件和真实错误继续保留，不做全局去重。

未识别的设备消息保留原意；列表限制长消息长度，详情和原始日志仍可查看完整消息。查询、关键字筛选、CSV 导出继续使用原始内容，导出格式仍为 `Time,Level,Content`。该页不新增配置或保存入口。

固定控件和布局位于 `RuntimeLogForm.Designer.cs`，三语文案沿用 `UiTheme.T` 和统一语言事件。语言切换保留查询输入、记录对象和原始内容。设计期使用不访问设备的流程日志示例。

验证入口：`tests/RuntimeLogs/Run.ps1`。除现有读写、筛选、异步刷新和导出检查外，还验证带内部取消异常的真实超时格式、名称含方括号的节点、旧暂停格式、原始堆栈导出、暂停重复请求、两种窗口尺寸及三语显示，并生成离线页面截图。
