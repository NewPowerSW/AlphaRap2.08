# 物料管理入口

物料管理继续使用原 ProductManagerForm 和 Product 权限项。左侧【主页】下方提供带图标和文字的【物料管理】入口；按原 MENU_Click 路由打开，不创建第二个配方管理器。

登录或切换权限后立即刷新导航绘制。无权限时入口保持可见并呈现禁用状态，有权限时可进入。原先底栏中的窄图标入口移至侧栏，底栏继续显示当前配方。

导航行统一为 38 像素加上下间距，兼容 1280×760、1280×800、1440×900、1600×1000。新增三语标题：物料管理 / Materials / Materiales。

离线回归 14/14，覆盖文字入口、父容器、权限禁用状态保留、选中高亮、原事件绑定、四尺寸和三语显示，以及首页报警表、整机状态与页面字体。没有启动机器 Load、运动、IO 写入或拍照。
