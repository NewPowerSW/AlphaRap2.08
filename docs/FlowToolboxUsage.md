# FlowChat 功能工具箱

主界面进入【流程】，选择模块和初始化页／自动页，勾选【编辑流程】。所有继承 `Flow_BaseForm` 的页面共用工具箱和节点编辑方式。完整开机、换型和调试顺序见 [AlphaRap 操作 SOP](AlphaRap操作SOP.md)。

## 工具箱中有什么

工具箱按轴、数字输入、数字输出、气缸、视觉、设备、常量表、托盘、流程与数据、本地保存等功能分组。具体条目来自当前已经建立的实际对象和该对象声明的方法；可以搜索名称，拖到画布，也可双击或按 Enter 添加。

例如，选择“X轴 · 移动到绑定表的点位”时，节点已经绑定这个轴和方法；双击只需确认目标点位、参数及下一步。工具箱不会另外创建轴、相机或设备。只需要判断已有数据时，添加【条件节点】。

**当前仅保留【现有功能】和【仅判断条件】。C# 脚本、代码模块、模块自动发现及其专用编辑入口已移除。** 旧 Script／Code 定义可读取，但校验和运行会拒绝执行；需明确选择现有功能或条件重新配置，或解除引用后删除。取消编辑保留原定义，不会自动把脚本解释成别的设备动作。

## 最短操作顺序

1. 在原轴、IO、视觉、Device 和常量等页面建立并配置实际对象；型号只用 ProductManagerForm 切换。
2. 在工具箱找到所需实际对象的动作，拖到当前模块画布。
3. 双击节点。在【动作设置】核对类别、实际对象、方法，为参数填固定值或点击【绑定数据】选择 Setting、Recipe、上下文或上游节点输出。轴点位只显示本轴绑定表中的有效点。
4. 在【下一步】设置 NEXT。只需顺序执行时保持【无条件通过】，选择目标；需要分支再添加 CASE，为各出口设置独立 AND／OR 条件。
5. 在【超时与调试】设置超时、报警号和可选执行前断点。
6. 节点【确定】提交内存草稿，流程【校验】通过后用主界面【保存】落盘。退出编辑，沿用主【初始化／启动】运行。

右键节点可编辑属性、切换执行前断点或删除。有下游输出引用时先解除；模块页面仍有 FlowChat 节点时不能删除页面。

## 数据、配方和资源

节点输出由所选方法声明，应用工程师无需另外编写输出函数。下游参数或条件通过【绑定数据 → 节点结果】选择模块、节点及字段。必须是当前运行及产品周期中已完成的有效结果；缺失、过期或其他产品的数据会报错，不以零代替。

Setting 独立于型号；Recipe、轴点位及 VPP 按 ProductManagerForm 当前配方加载。流程工程与对象身份是机器配置。先在原页面修改资源、配方参数和点位并主保存，再运行；启动使用已提交快照。

视觉读输出／存图的【来源拍照节点】只选择同一 VPP 的匹配执行节点，自动绑定它的 RunId。DataForm 保存动作直接列出当前生产表的业务字段，需要逐项绑定，成功后返回 RecordId、Path；主保存配置不会代替实际生产记录写入。

## 主保存与生成源码

主【保存】从同一快照保存机器 Setting 目录中的 `FlowPrograms.xml`（V3），并生成所属 Form 的 `.Flow.g.cs` 和 `FlowSources.manifest.xml`。开发环境通常生成到 `AlphaRap/GeneratedFlows`，发布环境通常生成到机器 Setting 的 `GeneratedFlows`，实际位置用【查看生成源码】及按钮提示核对。

生成文件是平铺的流程定义，由现有运行器调度，不建立第二套执行器。重新加载以 XML 为准。删除节点后再次保存会同步删除生成定义；末节点删除后保留空定义。手写 `.cs`、`.Designer.cs`、`.Custom.cs` 不覆盖。受管理文件手改会阻止覆盖，应先处理冲突，不能直接删保护标记。

保存配置、生成源码、编译部署是不同动作。节点配置主保存后供后续启动使用；修改宿主或 SDK 方法实现仍需重新编译部署，主 Save 不会重建正在运行的 EXE 或热替换 DLL。

## 如何扩展实际能力

已有类型新增实例通常只需在原页面配置。全新协议或业务方法由开发人员在实际对象或适配器中实现，并通过 `IFlowObject.GetFlowMethods` 声明方法、参数、三语名称和结果字段，节点编辑器与工具箱随后复用该契约。

外部应用已有实例可由宿主通过 `FlowExternalResources.Register/Replace/Unregister` 登记；保留稳定身份，遵守主界面线程、空闲和引用保护规则。登记不会替调用方构造、连接或释放硬件对象。当前不支持通过继承代码节点类扫描并拖入工具箱。

节点调试使用原断点、单步和继续入口。暂停在节点边界生效；停止或超时请求取消，等待真实调用结束再释放资源。现场动作、超时、断线及数据写入仍需联调验证。
